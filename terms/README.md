# 검토 전용 약관 초안

이 디렉터리는 APP-39의 23개 앱별 한국어·영어 초안입니다. 현재 시행되는 약관이 아닙니다. 빈칸·운영 정보·앱 식별·상품·개인정보처리방침·시행일을 확정하기 전 master 병합 또는 게시하지 마세요.

특히 networth는 fleet package(com.threej.asset_ticker)와 코드 package(com.threej.networth)가 다르므로 Console 확인 전 제출하지 마세요. 히트세이프는 기존 https://heatsafe.app/terms.html 및 영어·일본어 URL을 우선 재사용합니다. 이 초안이 기존 약관을 대체하지 않습니다.

기존 GitHub Pages 설정은 master:/ legacy입니다. 이 브랜치는 검토용이며 공개·시행 승인을 포함하지 않습니다. 전체 근거·앱별 URL 매핑은 app-fleet의 docs/compliance/play-terms/README.md를 확인하세요. noindex는 비공개 접근 제어가 아닙니다.
